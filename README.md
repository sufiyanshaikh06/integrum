# Integrum: AI-Powered Student Success Platform

Integrum is an integrated academic, productivity, and career management ecosystem designed for students.

## Architecture
- **Frontend:** React + Vite + Tailwind CSS + shadcn/ui
- **Backend:** Node.js + Express + Prisma + PostgreSQL
- **Shared:** Zod schemas, TypeScript types, and constants.

## Development
Run the development environment from the root workspace:

```bash
npm install
npm run dev
```
